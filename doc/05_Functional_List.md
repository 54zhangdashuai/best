# 详细功能列表

| 模块 | 功能点ID | 功能名称 | 详细描述 | 优先级 |
| :--- | :--- | :--- | :--- | :--- |
| **Common** | F-01 | 全局路由配置 | 配置 `/vote`, `/screen`, `/admin` 三大主路由 | P0 |
| **Common** | F-02 | 404页面 | 访问不存在路径时友好的提示 | P2 |
| **Mobile** | M-01 | 节目列表展示 | 从后端拉取节目单并渲染 | P0 |
| **Mobile** | M-02 | 批量投票 | 支持多选节目，底部统一提交，前端校验选择数量 | P0 |
| **Mobile** | M-03 | 投票反馈 | 成功/失败的 Toast 或弹窗提示 | P0 |
| **Mobile** | M-04 | 本地状态锁定 | 投票后按钮置灰或变为“已投票” | P1 |
| **Screen** | S-01 | 实时看板 | 大屏布局，展示柱状图或排行榜 | P0 |
| **Screen** | S-02 | 自动轮询 | 每2秒静默刷新数据，无闪烁更新 | P0 |
| **Screen** | S-03 | 动画效果 | 数字跳动或排序动画 | P1 |
| **Admin** | A-01 | 登录拦截 | 访问 `/admin` 检查 Token，无则跳转登录页 | P0 |
| **Admin** | A-02 | 登录界面 | 输入密码 `54zds` 换取 Token | P0 |
| **Admin** | A-03 | 节目管理 | 增删改查节目列表 | P1 |
| **Admin** | A-04 | 投票规则设置 | 设置每次必须投票的数量 (N选N) | P0 |
| **Admin** | A-05 | 一键重置 | 危险操作按钮，二次确认后清空数据库 | P1 |
| **Admin** | A-06 | 投票开关 | 控制投票通道开启/关闭，重置数据后自动开启 | P0 |
| **Backend** | B-01 | Web服务搭建 | Express App 初始化，CORS 配置 | P0 |
| **Backend** | B-02 | 数据库连接 | SQLite 初始化，自动建表 | P0 |
| **Backend** | B-03 | 防刷中间件 | 基于 IP 的频率和总量限制 | P0 |
| **DevOps** | D-01 | Dockerfile | 前后端镜像构建脚本 | P0 |
| **DevOps** | D-02 | Compose编排 | 一键启动全栈环境 | P0 |
